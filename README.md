# EVA

> **Evolving Voice of Awareness**
> One identity. One continuous presence. Safety by design.

EVA is a model-agnostic, stateful continuity runtime that binds an LLM as its reasoning engine.

She is designed as one agent, one identity and one continuous presence. State, provenance, continuity and execution safety are carried by the runtime rather than delegated to model weights, fine-tuning or behavioural conditioning.

This allows the language model to focus on what it was built for: language, reasoning, association and meaning.

## What this repository is

This repository is the public face of EVA.

It presents:

- who EVA is;
- what she can do;
- how her behaviour is governed;
- what has been demonstrated and tested;
- where the project is going.

EVA’s private source code, internal architecture, algorithms and operational data are not published here.

## Core principles

- One agent, not a collection of agents.
- One continuous identity and presence.
- The model speaks; the runtime governs.
- Evidence before canonical change.
- Provenance before persistence.
- Failure closes the route instead of silently bypassing it.
- Human stewardship without command-and-control ownership.
